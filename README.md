## How to publish on GitHub Pages

1. Create a public GitHub repository or open your existing repository.
2. Upload all files from this folder to the root of the repository.
3. Go to Settings -> Pages.
4. Under Build and deployment, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
5. Save and wait a few minutes.

## Optional custom domain

If you want to use:

ownerportal.oceanfrontcondos.lk

add that in GitHub Pages custom domain settings and create this DNS record:

- Type: CNAME
- Host/Name: ownerportal
- Target/Value: YOUR-GITHUB-USERNAME.github.io
